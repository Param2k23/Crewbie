# Crewbie Mission Control (Agent 06)

Discover (activity/opportunity discovery) + Mission Control (3D Negotiation Arena with a 2D fallback, planning intent, itinerary and judge intervention), driven only by
`AgentEvent`s from `docs/implementation/CONTRACTS.md`. Owner paths: `apps/web/`, `services/realtime/`,
`tests/realtime/`, `docs/mission-control/`.

## Run it (no backend needed)

```bash
cd apps/web
npm install
npm run dev            # http://localhost:3000   (Campus Pulse at /, Mission Control at /arena)
```

* `/arena` opens **Quick Plan** (`?mode=quick`): four students plan an evening. `?mode=weekend` is **Weekend Plan**
  (two-day trip: budget conflict, departure conflict, then a counteroffer). Press **Play** or **Step →**; playback holds
  with 2 accepted, 1 conditional, 1 silent and nothing confirmed. Use **Judge intervention** to change a hard budget,
  block a time window, or withdraw a participant (see [DEMO_SCRIPT.md](DEMO_SCRIPT.md)).
* `/arena?mode=fixture` replays `agent_events.json` unchanged (read-only; ends backend-confirmed).
* `?view=2d` forces the accessible 2D view; **V** toggles 2D/3D. Keys: Space play/pause, → step, R reset.

## Live SSE bridge (optional)

```bash
# terminal 1, from the repo root (Python 3.10+, stdlib only)
python3 -m services.realtime.dev_server --replay --interval 1.0
# terminal 2
cd apps/web && npm run dev
# browser: http://localhost:3000/arena?mode=live  -> Connect (defaults: http://127.0.0.1:8787, session_trip_001)
```

The dev server is read-only. Its judge route answers **501** on purpose; the UI then reports "unavailable, nothing was
changed" rather than faking a replan. Set `NEXT_PUBLIC_CREWBIE_API_URL` to prefill the API base URL.

## Tests

```bash
cd apps/web && npm test                    # vitest: reducer, sanitizer, replay, judge, SSE, Campus Pulse, 2D fallback (96 tests)

```
